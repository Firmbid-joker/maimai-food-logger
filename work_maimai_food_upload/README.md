# 🍔 麦麦食感记录助手

> 基于 WorkBuddy + 麦当劳官方 MCP 的智能点餐助手：少纠结、多省钱、护肠胃。🎲 点餐骰子是门面功能。

## 🎯 目标用户

- **选择困难症患者**：纠结吃啥，用骰子 10 秒决策；
- **程序员群体**：1024 程序员节，要省钱套餐 + 肠胃护佑；
- **肠胃敏感人群**：想记录并避开让自己不舒服的餐品组合；
- **麦当劳常客**：想自动用券、算清每单实付。

---

## ✨ 特色功能

- **🎲 点餐骰子（门面）**：一句话摇出今天吃啥，解决选择困难（随机但聪明，不是盲抽）。
- **💸 程序员标配套餐推荐**：自动查门店券，匹配最优优惠，预估券后价，推 1024 专属套餐。
- **💡 1+1 随心配**：自动组 1+1 组合按性价比排序，省钱不踩雷。
- **📒 个人用餐日志**：持续记录消费金额、口味评价与肠胃反馈。
- **🍔 肠胃风险避雷**：基于个人记录做个性化避雷推荐，差异化创新。
- **🪪 个人画像卡**：生成「你是XX星人」可分享趣味卡。
- **🧾 历史订单自动同步**：读取你自己的麦当劳订单，自动生成用餐记录草稿，免逐条手录。

四大能力 + 二项增强，既有好玩骰子满足趣味，又有消费记录 + 肠胃学习的完整业务闭环，深度更强。

## 💬 交互示例

### 程序员套餐场景
> 用户：给我推荐程序员节麦麦套餐，预算30

> 🖥️ 程序员经典套餐推荐：**巨无霸双牛肉饼 + 大薯 + 零度可乐**
> 原价 32 元，使用【1024 程序员节券】，券后实付 28 元
> ⚠️ 肠胃提示：大薯油炸 + 碳酸冷饮，熬夜写代码易胀气腹痛。
> 优化方案：换成**热红茶**，风味损失小，大幅降低肠胃刺激。
> 🎲 你也可以直接摇骰子，随机换别的套餐。

### 骰子场景
> 用户：纠结了，帮我摇个麦麦骰子，预算20

> 🎲 正在摇动麦麦骰子……
> 本次摇出：**麦香鸡套餐**
> 套餐详情：麦香鸡堡 + 热红茶，可用优惠券，实付 18.9 元
> 历史提示：你没有这个套餐的腹痛记录，肠胃刺激较低。

### 1+1 随心配场景
> 用户：来个 1+1，性价比高的

> 💡 1+1 随心配推荐：**麦辣鸡腿堡 + 玉米杯**
> 组合价 21.5 元，叠加【随心配专属券】券后 19.9 元
> 性价比 ★★★★☆；肠胃提示：油炸主菜配温热玉米杯比冰饮更护胃。

### 个人画像卡场景
> 用户：给我做个画像

> 🪪 你的麦麦画像：**板烧星人** ⭐
> 最爱：板烧鸡腿堡（出现 8 次）；月均花费 ¥186，已累计省钱 ¥53
> 雷区：板烧 + 冰可乐易腹胀，建议换热红茶

## 🔌 MCP 接入说明

本 Skill 调用官方麦当劳 MCP，所需工具：

- `query-meals`（菜单查询）、`query-meal-detail`（套餐组成 / 可替换项）、`list-nutrition-foods`（营养查询）
- `query-nearby-stores`（附近门店）、`query-store-coupons`（门店可用券）、`available-coupons`（麦麦省可领券）、`query-my-coupons`（我的券）
- `calculate-price`（真实券后价计算）、`campaign-calendar`（活动日历）、`now-time-info`（当前时间）、`order-list`（历史订单）

> 完整调用流程与「刻意不使用的工具」清单见仓库内 `MCP_INTEGRATION.md`。

**接入步骤：**

1. 在 WorkBuddy 中连接大赛提供的「麦当劳 MCP」服务（按官方活动页指引完成授权）。
2. 将本仓库 `SKILL.md` 放入 `~/.workbuddy/skills/maimai-food-logger/`。
3. 启用技能后即可对话；所有菜单 / 价格 / 优惠券数据均**实时来自官方 MCP，不在仓库内硬编码**。
4. MCP 仅提供查询与推荐能力，**不能自动领券或下单**（大赛限制）。
